Overview

Children learned novel object labels from a video presentation that either did or did not include a socially contingent robot (NAO). Word-learning accuracy was measured with a 12-trial forced-choice test, and engagement was coded from video across multiple behavioural channels. The autistic sample was characterised using standardised diagnostic and developmental measures (ADOS-2, MSEL, Vineland-3), which were used for sample description rather than as eligibility criteria.

The study was preregistered on the Open Science Framework prior to data collection: osf.io/hg859. Departures from the preregistered protocol are documented in the deviation log.

This repository is the canonical public archive of the project's open science materials. It exists to support transparency and computational reproducibility of the analyses reported in the manuscript.

Data

All shareable datasets live in data/deidentified/. Every participant ID in this deposit (datasets, notebook output, and figures) is a re-coded public ID that cannot be linked to the identifiers used during data collection. The re-coding is performed by deidentify_release.R; the mapping is held securely by the authors and is not deposited.

Key files

  • analysis_main_deidentified.csv: the main analysis dataset (one row per participant)
  • test_trials_long.csv: trial-level word-learning test data
  • engagement_cleaned_intervals.csv: interval-level engagement coding
  • data_dictionary.xlsx: variable definitions, pair with every dataset
  • checksums.md: MD5 checksums for every released dataset

Data-access statement. The raw source data are not shared because they contain individual-level clinical and developmental scores on a small autistic sample, for which the combination of quasi-identifiers carries a real re-identification risk. Requests for access to the underlying data may be directed to the corresponding author and are subject to ethics approval and a data-sharing agreement.

Code and how to reproduce

The analysis was conducted in R 4.5.3. Exact package versions are listed in computational_environment.md and in the Session Info section of the rendered notebook.

Table 2 Analysis code
FilePurpose
Social_Robot_Word_Learning_Analysis.RmdMain analysis notebook, the primary reproducibility artifact. Knits to the HTML notebook in outputs/
revision_recompute.RRevision re-analysis script
revision_model_B.RRevision Model B script
simr_power_robot_fixed.RPower analysis (simr)
deidentify_release.RProduces the de-identified datasets from the secure source files

What reproduces from the shared data. The word-learning and engagement analyses (notebook Sections 5 to 10) run from the de-identified datasets in data/deidentified/. Two parts require the secure source files and therefore do not re-run from the public deposit: the interrater-reliability computation (Section 3.4, raw coding workbooks) and the covariate screening on exact age and clinical scores (Section 7.1.5; the released main dataset carries banded age and banded clinical scores instead). The full analysis trail for those sections is visible in the rendered notebook.

Materials

Everything needed to run a replication is in materials/. Named-person contact details and university-identifying text have been removed from these files for public release; investigator names remain in investigator lists, as on the published paper.

  • Replication Protocol (also as .docx): step-by-step procedure for running the study
  • Engagement coding manual (also as .docx)
  • Robot scripts: NAO Social Robot Interaction Script and NAO play activity script
  • Stimuli: the 15-page storybook and the A and B picture-choice arrays. The picture arrays include NOUN novel objects (Horst & Hout, 2016); cite and attribute NOUN accordingly
  • Coding and scoring instruments: coding templates, scoring sheet, scale outline, and checklist (browse the materials folder)
  • Recruitment and ethics templates: blank consent, recruitment letter, debrief letter, social story, centre director information sheet, ethics application form

Note. The Mullen Scales of Early Learning are copyrighted test content and are not redistributed; cite the published test instead. The novel-word audio is embedded in the eBook presentation; the storybook pages and robot scripts document the words and their referents. See materials/README.md for the full inventory.

Figures and rendered analysis

The full rendered analysis notebook, with every model, table, diagnostic, and a plain-language summary after each main result, is available as a single HTML file: Social_Robot_Word_Learning_Analysis.html.

All manuscript figures are in outputs/figures/ as PNG and PDF, numbered as in the manuscript (Figure 1a/1b participant flow through Figure 10 engagement by group and channel).

# data/raw/ — NOT SHARED

This folder is intentionally empty in the public release.

Raw, identifiable, and clinically sensitive source files (engagement coding
workbooks, by-coder scoring files, and the combined ADOS-2 / MSEL / Vineland-3
score file) are held securely in the institutional store and are not deposited
to OSF or GitHub. Their combination of quasi-identifiers (age, gender,
diagnostic status, standardized scores) on a small autistic sample carries a
real re-identification risk.

Access to the underlying data may be requested from the corresponding author
and is subject to ethics approval and a data-sharing agreement. See the
project README for the data-access statement.

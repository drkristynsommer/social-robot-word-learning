# materials/

Study materials for reproduction. All named-person email addresses, phone
numbers, and university-identifying text (institution name and email domains)
have been removed from these files for public release. Investigator/author names
remain in investigator lists, as on the published paper.

> All study-team personal names have been removed from every document in this
> folder (visible text, hyperlinks, and file metadata), alongside the earlier
> removal of contact details and the university name.

## Deposited here

- `engagement_coding_manual.md` / `.docx` / `.pdf` — summary of the engagement coding scheme.
- `Engagement Coding Template.docx`, `NAO coding scheme.docx`, `hard copy coding template.docx` — coding guides/instruments.
- `Scale Outline Document.docx`, `Scoring Sheet.docx`, `ASD Word Learning.Checklist docx.docx` — coding/scoring instruments.
- `NAO Social Robot Interaction Script.docx`, `NAO play activity script.docx` — robot dialogue/scripts.
- `stimuli/` — the Storybook (15 pages) and the A and B picture-choice arrays (15 each). The picture arrays include NOUN novel objects (Horst & Hout, 2016); cite/attribute NOUN accordingly.
- `iPad NAO Learning Task QA Report.pdf` — internal QA report on running the iPad/NAO web app. Device passcode, internal IP addresses, and staff names redacted. (Contains screenshots; these show the task UI, not participant data.)
- `Social Story.pdf` — child-facing social story (all personal names removed).
- `Informed Consent.docx` — blank consent template.
- `Recruitment Letter.pdf`, `Debrief Letter.pdf`, `Centre Director Information Sheet.pdf` — recruitment/debrief templates.
- `HREA Output Form.pdf` — ethics application form (protocol number removed from filename and content).
- `Supplementary_Measures_Description.md` / `.docx` / `.pdf` — description of the standardized measures.

## Deliberately excluded

- **Mullen Scales of Early Learning PDF** — copyrighted test content (Pearson/AGS). Not redistributed; cite the published test instead.
- **`Participant Descriptions.xlsx`** — individual-level (Gender, Participant ID, free-text Description). Not deposited. The free-text Description column must be reviewed/cleaned or aggregated locally before any release.

## Notes

- The novel-word audio is embedded in the eBook presentation and is not
  archived as separate audio files; the storybook pages and the robot scripts
  document the words and their referents.
- The 12-trial picture-choice test is fully specified by the A and B picture
  arrays in `stimuli/` together with the Scoring Sheet.
- The experimental setup and modelling-video figures are in
  `outputs/figures/` (Figures 5 and 6), as numbered in the manuscript.
